# v0.8 — Release-Bound Benchmark Execution and Corpus I/O Hardening: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make benchmark execution provably bound to a frozen corpus release, harden every corpus read and artifact write, and record a deterministic, verifiable run receipt.

**Architecture:** One bounded corpus loader in `scripts/` serves all three benchmark CLIs. A new pure module `src/benchmark/execution.ts` owns release binding and the `benchmark-run-record-v1` receipt. A new `scripts/artifact-io.ts` owns atomic, refuse-by-default publication. `scripts/benchmark-verify.ts` re-verifies and replays. `benchmark-report-v2` is byte-frozen; the receipt is what binds a run to a release.

**Tech Stack:** Node 24, TypeScript ESM with native type stripping (`./x.ts` specifiers), `node --test`, `node:crypto`, `node:fs`. No new dependencies.

**Spec:** `docs/technical/BENCHMARK_EXECUTION_BINDING_AND_CORPUS_IO_HARDENING.md` (committed at `5e0fd83`). Read both; the spec argues the case, this plan sequences the work.

## Global Constraints

- Baseline `origin/main` = `e72e77a` (v0.7 merged). Branch: `feat/aporia-v0.8-execution-binding-corpus-io-hardening`.
- Offline and local only: no network, provider, crawl, remote publish, auth, billing, DB-backed review, or multi-tenancy.
- `src/benchmark/**` may import only `src/core/**`, sibling benchmark modules, and `node:` builtins (`scripts/check-boundaries.ts` enforces `src/**` only; the convention is documented in `docs/technical/MODULE_BOUNDARIES.md`). All filesystem IO stays in `scripts/`.
- `accuracyClaimable` is the literal `false` in every artifact. Never invent a case, reviewer, label, timestamp, source revision or permission.
- `benchmark-case-v1`/`v2`, `benchmark-report-v2` (including its `status` enum and existing digest fields), legacy submissions and adjudications stay readable. `evidence-aggregation-v1` default unchanged. ADR-025/026/027 statuses unchanged; ADR-028 is **Proposed**, not owner-accepted.
- Owner-approved decisions: (1) report text bytes frozen, identity via canonical hash; (2) reuse existing limits, no bound loosened, per-file read ceiling stays `maxCaseBytes = 262144`; (3) unsafe ids refused in validator **and** writer; (4) existing targets refused unless `--overwrite`.
- Strict TS: `exactOptionalPropertyTypes` (omit a key rather than assign `undefined`), `erasableSyntaxOnly` (no constructor parameter properties), `noUnusedLocals`. Prettier reformats on save — re-read before a SearchReplace. `*.md` is prettier-exempt. LF enforced by `.gitattributes`.
- Every task: write the failing test first, run it, implement minimally, run `npm run test` (or the focused file) green, then `npm run check` green before committing. Never commit a red tree. PowerShell: `;` separators, never `&&`, no `head`.
